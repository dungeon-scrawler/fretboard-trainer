# fretboard-trainer
A simple "flashcard" app for learning the fretboard.

100% vibe coded with Google Gemini.

## How to use
Simply select an exercise duration (30s, 60s, or 120s) and toggle the notes and strings you want to practice on. Finally, set a time interval for how long each note will remain visible on the screen.

Functionally, the app takes the notes you select and throws them in a "bag". At the beginning of each interval, a new note is pulled from the bag and displayed, until you've seen every note in your selected set. Then, all the notes are thrown back into the bag and the process starts again until you run through your entire configured duration.
